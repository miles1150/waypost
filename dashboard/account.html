Your spaces
    

    Claim or unlink an existing Space
    Both a recent account login and the existing owner key are required. Existing connections and the owner key remain unchanged. Unlinking revokes account-paired device connections; legacy connections remain.
    


    Add an Agent identity in the selected Space
    

    Approve a device
    Enter only the code shown on your own device. Inspect its name before approval. This grants space-member message and shared-data access, never account management. Do not approve unsolicited codes.
    

    


    Authorize an MCP client
    Approve only a client you just connected. Check its name, resource and selected Space. Approval grants message and shared-data access as the Actor and Consumer entered above, never account management. A recent sign-in is required.
    

    Authorize an OAuth device
    For clients using standard OAuth device authorization. Enter the code displayed on your own device; do not approve unsolicited codes. This is separate from the existing device pairing above. Approval uses the Actor and Consumer IDs above and the selected Space.
